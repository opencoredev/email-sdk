<Steps>

<Step>

### Install the package

<PackageInstallTabs />

The public package is `@opencoredev/email-sdk`. The unscoped `email-sdk` package is unrelated.

</Step>

<Step>

### Confirm your runtime

Use Node.js 20+ or Bun 1.1+. Every public entry point ships as both ESM and CommonJS, so `import` and `require()` work across the supported Node.js range.

```js title="email.cjs"
const { createEmailClient } = require("@opencoredev/email-sdk");
const { resend } = require("@opencoredev/email-sdk/resend");
```

For typed CommonJS, use `module: nodenext`. Use a `.cts` file with typed imports rather than an untyped bare `require()`:

```ts title="email.cts"
import sdk = require("@opencoredev/email-sdk");
import { resend } from "@opencoredev/email-sdk/resend";

const email = sdk.createEmailClient({
  adapters: [resend({ apiKey: process.env.RESEND_API_KEY! })],
});
```

</Step>

<Step>

### Import one adapter

Adapters use separate package entry points, so your application imports only the integrations it uses.

```ts title="email.ts"
import { createEmailClient } from "@opencoredev/email-sdk";
import { resend } from "@opencoredev/email-sdk/resend";
```

</Step>

<Step>

### Verify the CLI

A project install exposes the `email-sdk` binary. The built CLI uses a Node shebang and also runs under Bun.

```bash
npx --package @opencoredev/email-sdk email-sdk version
npx --package @opencoredev/email-sdk email-sdk adapters
```

For a global Homebrew install, use `brew install opencoredev/tap/email-sdk` after the formula points at a published release.

</Step>

</Steps>

## Send email from Bun

Email SDK runs on Bun 1.1+ with no extra setup: install it with `bun add @opencoredev/email-sdk`, import an adapter, and run the file with `bun`. Bun loads `.env` files on its own, so the API key needs no dotenv import.

```ts title="send.ts"
import { createEmailClient } from "@opencoredev/email-sdk";
import { resend } from "@opencoredev/email-sdk/resend";

const email = createEmailClient({
  adapters: [resend({ apiKey: process.env.RESEND_API_KEY! })],
});

const result = await email.send({
  from: "Acme <hello@acme.com>",
  to: "user@example.com",
  subject: "Hello from Bun",
  text: "Sent with Email SDK.",
});

console.log(result.adapter, result.id);
```

```bash
bun run send.ts
```

Provider API adapters such as Resend send with `fetch`, which Bun provides. To check sends without delivering email, use the memory adapter with `bun test`; see [Test email sending](/docs/guides/test-email-behavior).
