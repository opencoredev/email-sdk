The docs site exposes the active navigation through formats that do not require scraping rendered HTML.

| Endpoint               | Purpose                                                     |
| ---------------------- | ----------------------------------------------------------- |
| `/llms.txt`            | Site-level LLM index, with archived versions listed last    |
| `/llms-full.txt`       | Combined current documentation and comparison text          |
| `/mcp`                 | MCP server: search the docs and read pages from an agent    |
| `/api/docs/pages.json` | JSON index of every page                                    |
| `/feeds/docs.jsonl`    | One schema.org JSON object per docs, compare, and blog page |
| `/schemamap.xml`       | Machine-readable surface map                                |
| `/docs/<path>.md`      | Raw Markdown for one current page                           |

Every page answers `Accept: text/markdown` with its Markdown at the same URL, and every rendered page has Copy as Markdown and Open in chat actions. Archived versions have raw Markdown routes too, at `/v<release>/docs/<path>.md`.

## Connect an MCP client

```bash
claude mcp add --transport http email-sdk https://email-sdk.dev/mcp
```

## Prefer canonical URLs

Use current `/docs/...` URLs unless you need behavior from a pinned historical release. Archived pages declare their current equivalent as canonical.

## Retrieve one page

```bash
curl https://email-sdk.dev/docs/reference/client.md
```

The response is the page's Markdown, with components such as adapter tables rendered as Markdown tables.

## Retrieve the full corpus

Use `/llms-full.txt` for a compact single request covering every docs and comparison page, or `/feeds/docs.jsonl` when your indexer wants discrete route records.
