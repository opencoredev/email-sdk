Use these guides when you are operating a production send path or building something that should live outside one send call: fallback routes, tests, reusable plugins, custom provider adapters, or community packages.

If you want to support a provider that Email SDK does not officially maintain, start with [Publish a community adapter](/v0.6.0/docs/guides/authoring/publish-community-adapter). Community adapters live in their own npm packages and can be listed in the docs without becoming official.
