Email SDK is an open-source project maintained by OpenCore. The fastest way to reach the maintainers is on GitHub. Issues and discussions are public, so others benefit from the answer too.

## Bugs and feature requests

Open an issue at [github.com/opencoredev/email-sdk/issues](https://github.com/opencoredev/email-sdk/issues). Include the package version, the adapter involved, and a minimal reproduction so the problem can be confirmed quickly.

## Questions and usage help

Start a thread in [GitHub Discussions](https://github.com/opencoredev/email-sdk/discussions). For integration patterns, check the [documentation](/docs) first: most setup and adapter questions are answered there.

## Security reports

Please do not file public issues for vulnerabilities. Report them privately through [GitHub security advisories](https://github.com/opencoredev/email-sdk/security/advisories/new) so a fix can ship before disclosure.

## Sponsorship

If Email SDK saves your team time, you can support ongoing maintenance through [GitHub Sponsors](https://github.com/sponsors/opencoredev).
